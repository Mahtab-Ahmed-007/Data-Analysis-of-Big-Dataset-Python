# 📊 Data Analysis with Big Datasets

This repository contains Exploratory Data Analysis (EDA) projects performed on multiple real-world datasets using Python. The objective of these projects is to analyze large datasets, clean and preprocess data, visualize insights, and prepare data for machine learning.

## 📂 Projects Included

### 🏠 1. House Price Analysis

- Performed data cleaning and preprocessing
- Handled missing values
- Conducted univariate and bivariate analysis
- Analyzed feature distributions
- Detected outliers
- Correlation analysis
- Feature engineering
- Data visualization

**Dataset:** `House_price.csv`

---

### 🩺 2. Diabetes Data Analysis

- Data exploration
- Missing value analysis
- Statistical summary
- Correlation analysis
- Distribution plots
- Outlier detection
- Health indicator analysis
- Visualization of important features

**Dataset:** `diabetes.csv`

---

### 🚗 3. Used Car Price Analysis

- Data cleaning
- Handling categorical variables
- Missing value treatment
- Exploratory Data Analysis (EDA)
- Price distribution analysis
- Feature relationship analysis
- Correlation heatmaps
- Business insights from used car market data

**Dataset:** `used_cars_data.csv`

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/Data-Analysis-With-Big-Dataset.git
```

### Install required libraries

```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn jupyter
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```

Open any of the notebooks and run the cells.
